## G2R.8A foundation — cancellable, blackout-gated portal state machine (2026-10-01)
- Created `frontend/src/pages/Galaxy/navigation/PortalController.js` as a host-independent pure controller with explicit `idle → approach → plunge → blackout → committed` phases. It only begins after normal navigation has arrived at a focused `black-hole` target; click/selection alone remains a regular focus in G2R.7.
- Ordinary motion uses bounded phase clocks (0.9 s approach and 1.3 s plunge); reduced motion skips camera flight and enters blackout directly. Repeated begin/commit, stale IDs, premature acknowledgements, invalid/oversized frame deltas and bad/external destinations are guarded. Default destination is `/`; the same controller supports a future local `/lab` without changing its state machine.
