# Portfolio Platform

A full-stack personal portfolio codebase with a **React/Vite frontend** and a separate **Node.js/Express backend**.

This repository represents a later iteration of my portfolio work, where the site moved beyond a static page into a real application structure with separate frontend and backend layers.

## Stack visible in the repository

**Frontend**
- React 19
- Vite
- Tailwind CSS
- Axios
- Lucide React / React Icons

**Backend**
- Node.js
- Express 5
- authentication dependencies with bcrypt and JWT
- MongoDB / Mongoose dependencies
- MySQL / Sequelize dependencies
- rate limiting, logging, caching, and UUID tooling

## Why this project matters

This project reflects the point where I started treating my own portfolio as a **software system** rather than only a static showcase: separating concerns, adding an API layer, and exploring more production-oriented backend tooling.
