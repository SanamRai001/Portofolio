# Native Blender stone study

Isolated experiment; PR #44's 2.5D preview stays unchanged. Uses the CC0 [Poly Haven Dark Rock](https://polyhaven.com/a/dark_rock) color, normal, roughness and displacement maps. Builds real welded stone geometry with hollow cavity, lid pivot, softened edges, emissive seam and separate studio camera. The original artwork is a visual target, not a texture projection. GitHub Actions produces GLB, editable Blender scene, provenance and front/rear/open renders. No runtime integration until visual review. Run with Blender 4.x: `blender -b -t 4 --python-exit-code 1 --python prototypes/native-stone-study/build.py -- /absolute/output`. Network is required for material download; no paid services. Triangle count, appearance, browser motion and export compatibility require verification.
